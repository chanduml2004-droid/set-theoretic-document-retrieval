HOW IT WORKS

Boolean set operations

AND · Intersection

Returns documents containing both terms. A ∩ B

OR · Union

Returns documents containing either term. A ∪ B

NOT · Complement

Returns documents that do not contain a term. U − A

The system tokenizes each document, builds an inverted index (term → document-ID set), and evaluates Boolean expressions using operator precedence: NOT, then AND, then OR.
